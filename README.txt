CAMINO STUDIO — sitio web
===========================
Estructura del proyecto:

CaminoStudio/
├── index.html              <- la pagina (referencia css/, js/, images/)
├── css/
│   └── style.css           <- todos los estilos
├── js/
│   └── main.js              <- toda la interactividad (menu, scroll, contador, cursor)
├── images/
│   ├── projects/            <- fotos de los 8 proyectos (ver LEEME.txt adentro)
│   └── team/                <- fotos del equipo (ver LEEME.txt adentro)
└── assets/                  <- favicon, logo u otros archivos de marca (opcional)

COMO PUBLICARLA
-----------------
1. Pon tus fotos en images/projects/ e images/team/ con los nombres indicados
   en cada LEEME.txt de esas carpetas.
2. Sube la carpeta CaminoStudio COMPLETA (con su estructura interna intacta)
   a tu hosting. No subas solo el index.html suelto: necesita las carpetas
   css/, js/ e images/ al lado para funcionar.

Opciones de hosting recomendadas para este tipo de sitio (HTML/CSS/JS puro,
sin base de datos):
  - Netlify (netlify.com): arrastras la carpeta CaminoStudio y listo, gratis.
  - Hostinger: subes por FTP o el administrador de archivos, de pago.
  - GitHub Pages: gratis, requiere subir a un repositorio de GitHub.

EDITAR TEXTOS
--------------
Abre index.html con cualquier editor de texto. Los estilos ya no estan ahi
dentro (estan en css/style.css) asi que el archivo es mucho mas facil de leer.
